## 第１章　ベイズ統計学
### 伝統的な統計学との違い

*   **頻度論の考え方**：「何度も繰り返した場合に、ある事象が起こる割合」を確率と捉えます。 例えば、「このコインは、無限回投げれば表が50%出るはずだ」と考え、手元のデータ（例：100回投げて55回表が出た）が、その「真の確率」からどの程度ずれているかを評価します。

*   **ベイズ統計学の考え方**：確率を「信念の度合い」や「確からしさ」として捉えます。 最初は「たぶん普通のコインだから、表が出る確率は50%くらいだろう」という**事前確率**（主観的な確率）からスタートします。 そして、実際にコインを投げて「10回中8回も表が出た」という新しいデータを得ると、「もしかしたら、このコインは表が出やすい（例えば80%くらい）のかもしれない」と、その信念を更新します。この更新された確率が**事後確率**です。

| 特徴 | 頻度論（一般的な統計学） | ベイズ統計学 |
| :--- | :--- | :--- |
| **確率の捉え方** | 客観的な頻度（何度も繰り返した時の割合） | 主観的な信念の度合い（確からしさ） |
| **アプローチ** | データから唯一の真実（母数）を推定する | 事前の信念をデータによって更新していく |
| **データの扱い** | データは変わりうるものと考える | 得られたデータは不変のものと考える |
| **結果の解釈** | 「仮説が正しいとした場合、このデータが得られる確率は〇%」 | 「このデータが得られた場合、仮説が正しい確率は〇%」 |


### ベイスの定理

*   `P(S)` **(事前確率)**: これまでの経験や知識からくる、Sが起こるだろうという確率
*   `P(X|S)` **(尤度)**: もしSが正しいとしたら、Xというデータが得られるもっともらしさ
*   `P(S|X)` **(事後確率)**: Xというデータを得た**後での**、Sが起こるだろうという更新された確率

条件付き確率について
$$
P(X, S) = P(X|S)P(S) = P(S|X)P(X)
$$
よって
$$
P(S|X) = \frac{P(X|S)P(S)}{P(X)} = \frac{P(X|S)}{P(X)} \cdot P(S)
$$

$P(X) = \sum_{S}P(X, S)$ より
$$
P(S|X) = \frac{P(X|S)}{\sum_{S}P(X|S)P(S)} \cdot P(S)
$$



### 具体例：迷惑メールフィルタ

ベイズ統計学は私たちの身近なところで活躍しています。その代表例が迷惑メールフィルタです。

1.  **事前確率**: まず、「あるメールが迷惑メールである確率」を大まかに設定しておきます（例えば10%など）。
2.  **データ（尤度）**: これまでの迷惑メールと判定された大量のメールから、「無料」「キャンペーン」といった単語がどれくらいの頻度で出現するかを学習します。 同様に、通常のメールでの出現頻度も学習します。
3.  **事後確率の計算**: 新しいメールが届いたとき、そのメールに「無料」という単語が含まれていたとします。この「『無料』という単語が含まれている」という事実（データ）を使って、ベイズの定理で「このメールが迷惑メールである確率」を再計算します。
4.  **判定**: 計算された事後確率が、設定したしきい値（例えば90%）を超えたら、そのメールは「迷惑メール」として分類されます。

このように、新しいデータ（メールの内容）を使って、迷惑メールである確率を柔軟に更新していくことで、フィルタの精度を高めています。

### ベイズ統計学のメリット

*   **データが少なくても推論できる**: 事前の知識や経験を活かせるため、データが少ない段階からでも分析を始められます。
*   **知識を柔軟に更新できる**: 新しいデータが得られるたびに、モデルを改善していくことができます。これは機械学習と非常に相性が良い性質です。
*   **直感的に理解しやすい**: 「仮説が正しい確率は80%」のように、結果が確率として直接的に表現されるため、直感的に理解しやすいです。


## 第２章　事前確率事後確率
### ベイズ更新：経験から学習する仕組み

ベイズ統計学の心臓部とも言えるのが、**ベイズ更新 (Bayesian Updating)** のプロセスです。これは「新しい情報を手に入れるたびに、ベイズの定理を使って信念（確率）を繰り返し更新していくプロセス」を指します。

ベイズ更新は、以下のステップを繰り返します。

1.  **事前確率の設定**: まず、現時点で持っている知識や経験に基づいた「もっともらしい」確率（事前確率）を設定します。
    *   例：「このコインの表が出る確率は50%だろう」

2.  **データの観測**: 新しいデータを観測します。
    *   例：コインを10回投げたら、8回表が出た。

3.  **事後確率の計算**: ベイズの定理を使い、事前確率と観測データを組み合わせて、更新された信念（事後確率）を計算します。
    *   例：「10回中8回表」という結果を踏まえ、表が出る確率は75%に更新された。

4.  **事後確率を次の事前確率へ**: ここが重要なポイントです。**計算した事後確率が、次の観測における新しい事前確率となります。**

この「**事後確率 → 次の事前確率**」というループを回すことで、データが増えるたびに、私たちの推論はより確からしいものへと継続的に改善されていきます。これは、人間が経験から学習していく過程を数学的にモデル化したものと考えることができます。


### 応用：逆問題とは

ベイズ統計学の考え方を応用した強力な分野の一つに「逆問題」があります。

一言でいうと、**逆問題とは「結果（観測データ）から、その原因を推定する問題」** のことです。これは、原因から結果を予測する **「順問題」** と対比すると分かりやすくなります。

#### 順問題 vs 逆問題

| | 順問題 (Forward Problem) | 逆問題 (Inverse Problem) |
| :--- | :--- | :--- |
| **方向** | **原因** → **結果** | **結果** → **原因** |
| **問い** | もし原因がこうだったら、結果はどうなるか？ | 観測された結果は、どんな原因によって生じたのか？ |
| **例** | 地震の震源地と規模が分かっている状態で、各地点での揺れを予測する。 | 各地の地震計で観測された揺れのデータから、震源地と規模を特定する。 |
| **例** | 人体の構造が分かっている状態で、CTスキャンの撮影画像をシミュレーションする。 | CTスキャンで撮影された多数の断層画像から、体内の3次元構造を再構成する。 |

#### なぜ逆問題は難しいのか？

逆問題が難しいのには、主に以下の理由があります。

1.  **解が一意に決まらない（非一意性）**: 同じ結果を引き起こす原因が、複数考えられる場合があります。
2.  **解が不安定になる（不良設定問題）**: 観測データに含まれるほんのわずかなノイズ（誤差）が、推定される原因に非常に大きな影響を与えてしまうことがあります。
3.  **情報が足りない**: 観測できるデータだけでは、原因を特定するのに情報が不足していることがよくあります。

#### 逆問題とベイズ統計学の関係

ここで、ベイズ統計学が強力なツールとして登場します。逆問題の「結果から原因を推定する」という構造は、ベイズの定理の「データを得て、仮説の確率を更新する」という考え方と非常に相性が良いのです。

*   **事前確率**: 「原因は、たぶんこんな感じだろう」という、あらかじめ持っている知識や仮定。（例：「この地域では、だいたいこの辺りで地震が起きやすい」）
*   **尤度**: 「もし、ある原因を仮定したら、今観測されているデータ（結果）がどれくらいの確率で得られるか」という計算。
*   **事後確率**: 観測データを踏まえた上で、「原因がこうである確率が最も高い」という更新された信念。

このように、逆問題という難しい問題に対して、ベイズ統計学は「手持ちの知識を総動員し、不確実性を含んだ形で、もっともらしい原因は何か」という答えを導き出すための、強力な枠組みを与えてくれます。
